Research

Accepted · IEEE DSAA 2026

CHART: Curriculum-guided Hierarchy-Aware relation classification via prompt tuning

Anushka Gupta, Soumya Bharadwaj, Posa Mokshith, Ashish Anand

A prompt tuning method that teaches the model from easy to hard examples and uses the label hierarchy. It beats baselines on TACRED, Re-TACRED and AmalREC, using LLM-as-a-Judge to estimate difficulty and a graph attention network (GAT) to add hierarchy.
